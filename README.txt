BUILD: Mở thư mục AutoAnswer bằng Android Studio, chờ Gradle sync, nối điện thoại Android 10+ (bật USB debugging), bấm Run.
Hoặc: Build > Build APK(s) > app/build/outputs/apk/debug/app-debug.apk.
SỬ DỤNG: Mở app > nhập API key > Lưu > Bật dịch vụ Trợ năng > mở app/web có câu trắc nghiệm > bấm nút nổi "▶ AI".
Android 10: chỉ đọc được chữ qua cây giao diện (Chrome và hầu hết app). Không có OCR ảnh (cần Android 11+).
Nếu Android chặn ("Restricted setting"): Cài đặt > Ứng dụng > Auto Trắc Nghiệm > ⋮ > Cho phép cài đặt bị hạn chế.
